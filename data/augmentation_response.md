To improve prediction of `num` (heart disease severity), we can generate **derived features** that capture *nonlinear relationships* and *domain-relevant ratios/interactions* that doctors use implicitly.

Below are **derived features** that can be *consistently and automatically computed* from your listed columns — no external data needed, and they can be generated by formulaic transformations (perfect for an LLM-based feature expansion pipeline).

---

### 🧠 1. Cardiovascular Efficiency & Risk Ratios

| New Feature              | Formula / Description                                                                                                                                                                              | Rationale                                                                 |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| **pulse_pressure**       | `trestbps_diff = systolic_bp - diastolic_bp` — but since only `trestbps` (resting systolic BP) is given, if diastolic unavailable, skip. If available, `pulse_pressure = trestbps - diastolic_bp`. | Indicates arterial stiffness and cardiovascular strain.                   |
| **chol_age_ratio**       | `chol / age`                                                                                                                                                                                       | Normalizes cholesterol to age — high ratio → high risk at younger age.    |
| **fbs_trestbps_product** | `fbs * trestbps`                                                                                                                                                                                   | Encodes both fasting blood sugar and BP — high in diabetic hypertensives. |
| **bp_chol_interaction**  | `trestbps * chol`                                                                                                                                                                                  | Captures combined metabolic load.                                         |

---

### 🫀 2. Exercise Response Features

| New Feature            | Formula / Description              | Rationale                                                                                              |
| ---------------------- | ---------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **heart_rate_reserve** | `thalch / age`                     | Normalized peak heart rate — low value suggests poor cardiac output.                                   |
| **stress_slope_index** | `(slope + 1) * (thalch - oldpeak)` | Encodes the ST segment slope pattern under stress; higher values correlate with ischemia.              |
| **exercise_impact**    | `thalch * (1 - exang)`             | If `exang` = 1 (exercise-induced angina), the product drops — helps discriminate patients with angina. |

---

### 🧩 3. Encoded Clinical States

| New Feature                 | Formula / Description                | Rationale                                       |
| --------------------------- | ------------------------------------ | ----------------------------------------------- |
| **is_hypertensive**         | `int(trestbps >= 140)`               | Binary indicator for hypertension.              |
| **is_hypercholesterolemia** | `int(chol >= 240)`                   | Binary indicator for high cholesterol.          |
| **risk_factor_count**       | `sum([is_hypertensive, fbs, exang])` | Simple additive risk count.                     |
| **sex_cp_interaction**      | `sex * cp`                           | Chest pain pattern often differs between sexes. |
| **restecg_abnormal**        | `int(restecg != 0)`                  | Whether ECG is abnormal.                        |

---

### 📊 4. Normalized and Nonlinear Transforms

| New Feature      | Formula / Description                                                                                         | Rationale                           |
| ---------------- | ------------------------------------------------------------------------------------------------------------- | ----------------------------------- |
| **log_chol**     | `np.log1p(chol)`                                                                                              | Stabilizes variance in cholesterol. |
| **log_trestbps** | `np.log1p(trestbps)`                                                                                          | Same for blood pressure.            |
| **oldpeak_sq**   | `(oldpeak ** 2)`                                                                                              | Penalizes large ST depressions.     |
| **thal_encoded** | One-hot or ordinal encode of `thal` (since categorical: 3 = normal, 6 = fixed defect, 7 = reversible defect). | Heart perfusion type is crucial.    |

---

### 🩺 5. Composite Scores

| New Feature                 | Formula / Description                                              | Rationale                                             |
| --------------------------- | ------------------------------------------------------------------ | ----------------------------------------------------- |
| **cardiac_stress_index**    | `(oldpeak * (1 + exang)) / (thalch + 1)`                           | Higher when ST depression and angina coincide.        |
| **metabolic_risk_index**    | `(chol * fbs * trestbps) / age`                                    | Encapsulates metabolic syndrome.                      |
| **oxygen_efficiency_index** | `(thalch / trestbps)`                                              | Proxy for heart rate response per unit of resting BP. |
| **cp_slope_interaction**    | `cp * slope`                                                       | Certain chest pain types + slopes predict ischemia.   |
| **risk_score_raw**          | `0.4*is_hypertensive + 0.3*fbs + 0.3*exang + 0.2*restecg_abnormal` | Composite risk approximation (not medical-grade).     |

### 🧮 6. Category Interactions (for encoding)

LLMs (or downstream preprocessing) can also expand categorical interactions:

* `(sex, cp)` pair as a combined category
* `(thal, slope)` pair
* `(ca, thal)` pair

These can be expressed as strings like `"thal_3_slope_2"` or numerically by hashing — both are consistent transformations.
